# lab1

В ходе работы была выполнена первичная очистка, токенизация и нормализация текстовых данных. Построена базовая генеративная модель на основе N-грамм.

В топ-30 слов попали стандартные стоп-слова и специфичные для данных текстов.
Убраны шумы вида @username, http\[s\]://link/, числа, смайлики.

При стемминге перплексия меньше, принято решение использовать стемминг.
Написана функция сглаживания Лапласса, с коэффициентов альфа.
Без сглаживания перплексия равна бесконечности.
Перплексия на трейне: 314
Перплексия на тесте: 573
Построены тексты через марковские цепи, ни одна из них не сгенерировала токен "\</s\>". Токены циклятся, поэтому воспроизводится одна и та же часть текста.
